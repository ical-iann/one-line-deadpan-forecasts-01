# One-Line Deadpan Forecasts

A deadpan weather forecast for Varnwick, a city that does not exist — rain falling sideways since 1987, umbrellas useless. Built for the [Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) bounty on make.fun.

Running `main.py` writes the single forecast line to `/output/entry.txt`.
